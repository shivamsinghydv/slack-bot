# Slack Bot

An automated Slack assistant built to listen to workspace events, handle custom slash commands, and streamline team workflows directly within your channels.

## Quick Start

### Pre-requisites: 
- NodeJS
  
### Get the bot running locally in two commands:

```bash
npm install
npm start
```
